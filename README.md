# 📊 Acompanhamento de Estudos em Python

Este projeto foi desenvolvido com o objetivo de acompanhar meu progresso
semanal de estudos e cursos, utilizando Python para organização, cálculos
e relatórios no terminal.

## 🚀 Funcionalidades
- Resumo semanal de tarefas
- Acompanhamento de cursos (Front-end e SQL)
- Cálculo de progresso percentual
- Estimativa de dias para conclusão
- Avaliação automática de metas
- Estrutura modular e organizada

## 🧠 Conceitos aplicados
- Funções e modularização
- Boas práticas de nomenclatura
- Lógica condicional
- Cálculos percentuais
- Organização de projetos Python
- Código limpo e legível
